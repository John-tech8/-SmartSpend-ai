#  SmartSpend AI

### AI-Powered Personal Finance & Smart Expense Management Platform

**SmartSpend AI** is an intelligent personal finance management platform designed to help individuals understand their spending habits, manage expenses, plan savings and make smarter financial decisions using AI.

The platform aims to simplify financial management through expense tracking, spending analytics, goal-based savings and an AI-powered financial assistant.

🌐 **Live Demo:** https://smartspend-aicomsci.netlify.app/

---

## 🚀 Key Features

### 📊 1. Financial Dashboard
- Overview of personal financial activities.
- Income and expense monitoring.
- Spending summaries and visual insights.
- Financial health overview.

### 💸 2. Smart Expense Management
- Record and manage daily expenses.
- Organise transactions by categories.
- Monitor spending patterns.
- Track financial activities.

### 🤖 3. AI Financial Assistant – Mini Buddy
An AI-powered conversational financial assistant designed to help users make better financial decisions.

Planned capabilities:
- Natural-language financial conversations.
- Personalised budgeting recommendations.
- Financial literacy assistance.
- Context-aware conversations.
- Multilingual AI responses.
- Voice interaction.
- Persistent conversation history using PostgreSQL.
- Powered by xAI Grok.

### 🎯 4. Goal-Based Savings Tracker
- Create personalised savings goals.
- Define target amounts and deadlines.
- Monitor savings progress.
- Calculate required savings contributions.
- Track progress towards financial goals.

### 📈 5. Financial Insights
- Understand spending behaviour.
- Identify unnecessary expenses.
- Analyse financial patterns.
- Receive actionable financial recommendations.

### 🌐 6. Multilingual Experience
- Language selection.
- Localised application interface.
- AI responses based on the selected language.

## 🧠 AI Integration

SmartSpend AI aims to combine conversational AI with personal financial management.

| Component | Purpose |
|---|---|
| xAI Grok | Conversational AI assistant |
| System Instructions | Control AI behaviour and response scope |
| PostgreSQL | Persistent chatbot conversation storage |
| Speech Synthesis | Voice playback |
| Speech-to-Text | Planned voice input integration |

The AI assistant is designed to focus on personal finance, budgeting, expense management and savings-related queries.
